# BeeVisual Launcher

## Что нужно (всё бесплатно)
- Обычный Python 3.12 с python.org (при установке поставь галочку "Add to PATH"). НЕ MSYS2.
- Интернет при первом запуске (качается Minecraft 1.21.4, Fabric, Java и Fabric API).

## Где что лежит
- Игра, моды, миры: `C:\Users\<ты>\.beevisual\minecraft`
- Настройки: `C:\Users\<ты>\.beevisual\config.json`
- Лог последнего запуска игры: `C:\Users\<ты>\.beevisual\logs\latest-launch.log`
- Клиент BeeVisual (когда будет готов): положи `beevisual-*.jar` в папку `mods` рядом с `main.py` / `BeeVisual.exe`,
  лаунчер сам скопирует его в игру и поставит Fabric API.

## Если что-то не работает
Пришли текст ошибки из окна лаунчера и содержимое `latest-launch.log`.
