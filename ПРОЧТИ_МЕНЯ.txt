BeeVisual - один файл BeeVisual.exe (лаунчер + клиент внутри + загрузка модов)

Ничего ставить на ПК не нужно. Сборка идёт на GitHub сама:
1) github.com -> New repository -> загрузи ВСЁ содержимое этой папки (вместе с папкой .github).
2) Сборка стартует автоматически (вкладка Actions, ~5-10 минут).
3) Справа на главной странице репозитория, раздел Releases -> BeeVisual.exe -> скачай и запускай.
